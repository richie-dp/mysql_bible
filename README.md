# MySQL 圣经 · mysql_bible

> 写给中高级开发者的 MySQL 深度手册
> 不讲 `SELECT` 怎么写，只讲**为什么这样写会慢、会锁、会丢数据**。

## 这是什么

一本以「机制 → 现象 → 定位 → 解法」为主线的 MySQL 技术手册。全书 8 卷 52 章，围绕一条数据库请求的真实生命周期展开，覆盖存储引擎、索引与优化器、事务与锁、复制与高可用、数据建模、性能诊断、版本演进、工程规范与业务实战。

**版本基线**：MySQL 8.0.x（LTS 8.4 标注差异），5.7 相关处显式标 `[5.7]`。

**不包含**：安装部署、SQL 语法教学、客户端工具使用、参数默认值罗列（默认值放附录速查表）。

## 写作约定

每章固定 7 段结构：场景切入 → 机制原理 → 关键结论 → 实验验证 → 常见误区 → 生产 Checklist → 延伸。

硬性要求：

- 所有"更快/更慢"必须有机制解释或实验数据，禁止"一般来说"
- 版本差异必须标注 `[5.7]` / `[8.0.13+]` / `[8.4]`
- 每章至少一张图（Mermaid 或 ASCII）
- SQL 必须能在 `labs/` 环境下直接跑通
- 文件名格式：`docs/ch{两位编号}-{kebab-case}.md`
